## Problem

### Displaying Height and Weight in C

A doctor measures the height and weight of a patient.

Use `int` to measure height and `short` to measure weight.

 **Expected Output:** 

```
Height: 175
Weight: 70

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-01T16:52:46.689Z  

```c_cpp
#include <stdio.h>

int main() {
    // Declare a short variable for weight and assign it the value 70
    int t=175;
    int a=70;
    printf("Height:%d",t);
    printf("Weight:%d",a);
    // Declare an integer variable for height and assign it the value 175
    
    // Print: "Height: " followed by the value of height
    
    // Print: "Weight: " followed by the value of weight

    return 0;
}

```
