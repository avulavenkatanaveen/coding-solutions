## Problem

### Displaying Product Quantity

Write a C program to declare and initialize a variable for a product's quantity. Display the value stored.

 **Expected Output:** 

```
Product Quantity: 50

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-29T16:14:28.879Z  

```c_cpp
#include <stdio.h>

int main() {
    
    // Declare an integer variable for quantity
    int x=50;
    
    // Print the quantity
    printf("Product Quantity: %d",x);
    
    return 0;
}

```
