## Problem

### Storing and Displaying Student Score in C

In this example, we demonstrate how to declare a variable, assign a value, and print it in  **C**. This method provides a simple way to store and display numerical values dynamically using basic syntax.

 **When executed, the code will show:** 

```
Student Marks: 87

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-29T16:12:40.531Z  

```c_cpp
#include <stdio.h>

int main() {
    // Declare variable
    int marks;
    
    // Assign value to the variable
    marks = 87;

    // Display the value
    printf("Student Marks: %d\n", marks);

    return 0;
}

```
